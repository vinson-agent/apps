# Solitaire (Klondike)

Kartu Klondike klasik, satu file index.html.

- Tap kartu: otomatis pindah ke fondasi / kolom yang cocok. Atau seret kartu.
- Tap tumpukan kiri atas untuk ambil kartu (mode Ambil 1 atau Ambil 3).
- Undo, tombol Selesaikan muncul saat semua kartu sudah terbuka.
- Permainan tersimpan otomatis di browser; rekor waktu per mode.
